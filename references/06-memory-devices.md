## 1. 存储器概述

### 1.1 基本结构

```
地址总线 A[n-1:0] ──► 地址译码器 ──► 存储阵列（2ⁿ × m 个存储单元）
数据总线 D[m-1:0] ◄── 读写控制 / 输出缓冲 ◄──┘
控制：CS（片选）、WE（写使能）、OE（输出使能）
```

- **字数（深度）**：存储单元的个数，由地址线数决定，`2ⁿ`；
- **字长（宽度）**：每个单元的位数，由数据线数决定，`m`；
- **容量**：`2ⁿ × m` bit，常写成「字数 × 字长」，例如 `1K×4`、`2K×8`；
- **存取时间**：从给出地址到数据稳定的时间，是存储器速度的核心指标。

注意：`1K = 1024`，不等于 1000；`1K×8` 的容量是 `8192 bit = 1 KB`（按 8 位字节计）。

### 1.2 分类

| 大类 | 特点 | 常见类型 |
|---|---|---|
| ROM（只读存储器） | 正常工作时只读，掉电不丢失 | 掩膜 ROM、PROM、EPROM、EEPROM、Flash |
| RAM（随机存取存储器） | 可读可写，掉电丢失（易失） | SRAM、DRAM |

---

## 2. ROM（只读存储器）

### 2.1 结构特点

ROM = **地址译码器 + 存储阵列 + 输出缓冲**，没有写数据通路（或写操作需要特殊条件）。给定地址，输出该地址单元的内容：

```
地址 A → 译码器选中某一行 → 该行存储单元的内容送到数据总线
```

ROM 的「存储阵列」本质是一张**真值表**：地址是输入组合，数据是输出。因此 ROM 可以直接实现组合逻辑函数——这正是第 7 章 FPGA 中 LUT 的思想来源。

### 2.2 ROM 的类型

| 类型 | 写入方式 | 擦除方式 | 特点 |
|---|---|---|---|
| 掩膜 ROM | 芯片制造时写入 | 不可擦除 | 成本最低，适合大批量固定程序 |
| PROM | 用户一次性烧写（熔丝/反熔丝） | 不可擦除 | 小批量、固定逻辑 |
| EPROM | 高压写入 | 紫外线照射整片擦除 | 可重复使用，但操作麻烦 |
| EEPROM | 电写入 | 电擦除（按字节） | 可在线改写，寿命有限 |
| Flash | 电写入 | 电擦除（按块） | 密度高、成本低，U 盘/固态盘/配置芯片 |

### 2.3 用 ROM 实现组合逻辑

把输入变量接地址端，把真值表的内容预先写入对应单元，输出即为函数值。

**例 2-1**　用 8×4 ROM 实现全加器

- 输入 `A、B、Cin` 接地址 `A2、A1、A0`；
- 输出取数据线的 `D3 = S`、`D2 = Cout`，`D1、D0` 不用。

| 地址 `A B Cin` | 和 `S` | 进位 `Cout` | 存储内容 `D3 D2 D1 D0` |
|---|---|---|---|
| 000 | 0 | 0 | 0000 |
| 001 | 1 | 0 | 1000 |
| 010 | 1 | 0 | 1000 |
| 011 | 0 | 1 | 0100 |
| 100 | 1 | 0 | 1000 |
| 101 | 0 | 1 | 0100 |
| 110 | 0 | 1 | 0100 |
| 111 | 1 | 1 | 1100 |

这种「查表法」不需要化简，改变逻辑只需改 ROM 内容，适合函数复杂、批量小的场合；缺点是容量随输入变量数指数增长（`n` 个变量需要 `2ⁿ` 个字）。

## 3. RAM（随机存取存储器）

### 3.1 SRAM 与 DRAM

| 项目 | SRAM（静态 RAM） | DRAM（动态 RAM） |
|---|---|---|
| 存储单元 | 6 个 MOS 管构成双稳态触发器 | 1 个 MOS 管 + 1 个电容 |
| 数据保持 | 通电即保持，无需刷新 | 电容会漏电，需周期性刷新 |
| 速度 | 快 | 较慢（有刷新开销） |
| 集成度 | 低（单元大） | 高（单元小） |
| 成本 | 高 | 低 |
| 用途 | Cache、小容量高速缓存 | 主存、大容量存储 |

### 3.2 引脚与读写

典型 RAM 引脚：

- 地址线 `A[n-1:0]`；
- 双向数据线 `D[m-1:0]`；
- 片选 `CS`（或 `CE`）：低有效时芯片工作；
- 写使能 `WE`：低电平写、高电平读；
- 输出使能 `OE`：控制数据输出缓冲。

读操作：地址稳定 → `CS` 有效 → `OE` 有效 → 数据线上出现数据；
写操作：地址稳定 → 数据线上给出数据 → `CS` 有效 → `WE` 有效（产生写脉冲）→ 数据写入。

**关键约束**：同一时刻只能有一个芯片（或一组芯片）驱动数据总线。未被选中的芯片必须处于高阻态，否则会发生**总线冲突**。

## 4. 存储器容量扩展

### 4.1 三种扩展方式

| 扩展方式 | 目标 | 地址线 | 数据线 | 片选 | 芯片数 |
|---|---|---|---|---|---|
| 位扩展 | 字长变宽 | 全部并联 | 分开，按位拼接 | 全部并联 | 位向倍数 |
| 字扩展 | 字数变多 | 低位并联，高位译码 | 全部并联 | 分开，由高位地址译码 | 字向倍数 |
| 字位同时扩展 | 字数、字长都变 | 低位并联，高位译码 | 分开，按位拼接 | 分开 | 字向倍数 × 位向倍数 |

**芯片数公式**：

```
芯片数 = (目标字数 / 单片字数) × (目标字长 / 单片字长)
```

### 4.2 位扩展

**目标**：用 `1K×4` 芯片组成 `1K×8`。

- 两片芯片的地址线 `A9～A0` 全部并联；
- 两片的 `CS`、`WE`、`OE` 并联，同时选中；
- 一片的数据线接 `D7～D4`，另一片接 `D3～D0`。

这样每次读写 8 位：高 4 位来自第一片，低 4 位来自第二片。地址空间不变（仍为 1K 个字）。

### 4.3 字扩展

**目标**：用 `1K×8` 芯片组成 `2K×8`。

- 两片的数据线 `D7～D0` 并联；
- 地址线 `A9～A0` 并联到两片；
- 用最高位地址 `A10` 经译码产生两个片选：`A10 = 0` 选中第一片（地址 `0x000～0x3FF`），`A10 = 1` 选中第二片（`0x400～0x7FF`）；
- 未被选中的芯片输出高阻。

字扩展的本质是：**用高位地址做「片选」，低位地址在片内寻址**。

### 4.4 字位同时扩展

**目标**：用 `1K×4` 芯片组成 `2K×8`。

- 字向：`2K / 1K = 2` 倍；位向：`8 / 4 = 2` 倍；
- 芯片数 = `2 × 2 = 4` 片；
- 把 4 片排成 2 行（字向）× 2 列（位向）：每行两片并联成 `1K×8`，两行再由高位地址选择。

具体设计见第 5 节。

## 5. 设计示例：1K×4 芯片扩展为 2K×8 存储器

### 5.1 需求分析

| 参数 | 目标 | 单片芯片 |
|---|---|---|
| 字数 | 2K = 2048 | 1K = 1024 |
| 字长 | 8 位 | 4 位 |
| 地址线 | `A10～A0`（11 根） | `A9～A0`（10 根） |
| 数据线 | `D7～D0`（8 根） | 4 根 |

芯片数：`(2048/1024) × (8/4) = 2 × 2 = 4` 片。

### 5.2 分组与地址分配

把 4 片分成两组（每组对应 1K 个地址），每组内两片做位扩展：

| 组别 | 片选条件 | 地址范围 | 组内芯片 | 负责数据位 |
|---|---|---|---|---|
| 第 0 组 | `A10 = 0` | `0x000～0x3FF` | 芯片 0、芯片 1 | 0 号：`D7～D4`；1 号：`D3～D0` |
| 第 1 组 | `A10 = 1` | `0x400～0x7FF` | 芯片 2、芯片 3 | 2 号：`D7～D4`；3 号：`D3～D0` |

### 5.3 连接方案

**地址线**：

- `A9～A0` 接到全部 4 片（片内寻址）；
- `A10` 接译码器，产生两组片选 `CS0'`、`CS1'`：
  - `CS0' = A10`（`A10 = 0` 时第 0 组有效）；
  - `CS1' = A10'`（`A10 = 1` 时第 1 组有效）。

若片选为高有效，则把两者互换（`CS0 = A10'`、`CS1 = A10`），实际连接时以芯片手册的有效电平为准。

**数据线**：

- 芯片 0 与芯片 2 的 4 位数据接 `D7～D4`；
- 芯片 1 与芯片 3 的 4 位数据接 `D3～D0`；
- 同一时刻只有一组芯片被选中，因此数据总线上只有一组在驱动。

**控制线**：

- 所有芯片的 `WE`、`OE` 并联，由 CPU 的读写信号统一控制；
- 写操作时，只有被选中组的两片同时写入，一次写入完整的 8 位。

### 5.4 连接示意

```
              ┌─────────────┐
 A9～A0 ─────►│ 芯片0 (1K×4)│──── D7～D4 ─┐
              └─────────────┘             │
              ┌─────────────┐             ├──► D7～D0（总线）
 A9～A0 ─────►│ 芯片1 (1K×4)│──── D3～D0 ─┤
              └─────────────┘             │
              ┌─────────────┐             │
 A9～A0 ─────►│ 芯片2 (1K×4)│──── D7～D4 ─┤
              └─────────────┘             │
              ┌─────────────┐             │
 A9～A0 ─────►│ 芯片3 (1K×4)│──── D3～D0 ─┘
              └─────────────┘

A10 ──► 译码/反相 ──► 第0组 CS'（A10=0 有效）
                  └─► 第1组 CS'（A10=1 有效）

WE、OE 全部并联
```

### 5.5 地址范围验算

| 地址（十六进制） | 二进制 `A10 … A0` | 选中组 | 片内偏移 |
|---|---|---|---|
| `0x000` | `0 000 0000 0000` | 第 0 组 | 0 |
| `0x3FF` | `0 011 1111 1111` | 第 0 组 | 1023 |
| `0x400` | `1 000 0000 0000` | 第 1 组 | 0 |
| `0x7FF` | `1 111 1111 1111` | 第 1 组 | 1023 |

总容量 `2K × 8 = 2048 × 8 = 16384 bit`，等于 4 片 `1K×4` 的容量之和（`4 × 4096 = 16384 bit`），一致。

### 5.6 设计要点

1. **片选译码**：只需要区分两组，用一根反相器即可；若要扩展到 4 组（4K×8），可用第 3 章的 2-4 译码器产生 4 个片选；
2. **高位地址用于片选**：`A10` 不再进入芯片的地址端，而是参与片选，这是「字扩展」的标志；
3. **低位地址全部并联**：`A9～A0` 同时接到 4 片，保证片内偏移一致；
4. **数据线分组**：位扩展时数据线按位拆开，不能并联，否则会短路；
5. **总线冲突**：务必保证任意时刻只有一组 `CS` 有效，未选中芯片输出高阻；
6. **时序**：地址与片选稳定后再给出 `WE` 或采样数据，注意存取时间与建立时间。

---

## 6. 与 CPU 连接的要点

1. **地址总线**：CPU 的地址线经译码产生片选，低位直接接存储器；
2. **数据总线**：多片存储器的数据线按位拼接后接到系统数据总线；
3. **控制总线**：`WE`、`OE`、`CS` 的时序必须匹配 CPU 的读写周期；
4. **地址范围计算**：根据片选逻辑反推每片的地址区间，避免地址重叠；
5. **速度匹配**：慢速存储器需要插入等待周期（wait state）。

## 7. 自测题

1. 容量 `2K×8` 的存储器需要多少根地址线、多少根数据线？总容量是多少 bit？
2. ROM 与 RAM 的本质区别是什么？
3. 用 `1K×8` 芯片组成 `4K×8` 存储器，需要几片？属于哪种扩展？
4. 用 `1K×4` 芯片组成 `1K×8` 存储器，地址线、数据线、片选如何连接？
5. 用 `2K×8` 芯片组成 `2K×16` 存储器，需要几片？如何连接？
6. 为什么未选中的存储器芯片输出必须为高阻？
7. SRAM 与 DRAM 的存储单元分别是什么结构？各有什么优缺点？
8. 用 `1K×4` 芯片组成 `2K×8`，若地址 `0x5A3` 被访问，应由哪几片芯片响应？

### 7.1 答案与解析

1. `2K = 2048 = 2¹¹`，需要 11 根地址线；8 位字长需要 8 根数据线；总容量 `2048 × 8 = 16384 bit = 16 Kbit`。
2. ROM 正常工作时只读、掉电不丢失；RAM 可读可写、掉电丢失。ROM 用于固定程序/常数/查找表，RAM 用于运行时的数据存储。
3. `4K/1K = 4` 片，只增加字数，属于**字扩展**；4 片数据线并联，用 2 位高位地址经 2-4 译码器产生 4 个片选。
4. 两片地址线 `A9～A0` 全部并联，`CS`、`WE`、`OE` 并联；一片数据接 `D7～D4`，另一片接 `D3～D0`；属于**位扩展**。
5. `16/8 = 2` 片，只增加字长，属于**位扩展**；地址线与片选全部并联，两片数据分别接高 8 位与低 8 位。
6. 数据总线是共享的，若多个芯片同时驱动，会出现电平冲突（甚至损坏器件）；未选中芯片输出高阻，相当于与总线断开。
7. SRAM 用 6 管双稳态触发器，速度快、无需刷新，但单元大、集成度低、成本高；DRAM 用 1 管 1 电容，单元小、密度高、成本低，但需要周期性刷新，速度较慢。
8. `0x5A3 = 0101 1010 0011`，`A10 = 1`，选中第 1 组（芯片 2、芯片 3）；两片同时响应，芯片 2 提供 `D7～D4`，芯片 3 提供 `D3～D0`。
