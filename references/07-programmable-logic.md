# 第 7 章 可编程逻辑器件：PLD、CPLD 与 FPGA

> 所属技能：`dsh-digital-logic-skill` ｜ 对应 SKILL.md「2. 知识覆盖范围」第 7 条「存储与可编程器件」中的可编程器件部分
> 前置知识：第 2 章（与或式、卡诺图）、第 3 章（组合逻辑）、第 6 章（存储器结构）。LUT 本质就是一片小 SRAM。
> 阅读方式：先理解第 1 节的「与阵列 + 或阵列」模型，再看第 5 节 LUT——它是 FPGA 的逻辑核心。

## 0. 本章速查表

| 概念 | 要点 |
|---|---|
| PLD | 可编程逻辑器件，用「与阵列 + 或阵列」实现任意与或式 |
| 编程点 | 熔丝、反熔丝、EEPROM、Flash、SRAM |
| PROM | 与阵列固定（地址译码），或阵列可编程 |
| PAL | 与阵列可编程，或阵列固定；一次性编程 |
| GAL | PAL 结构 + EEPROM + 输出宏单元，可反复擦写 |
| CPLD | 多个 PAL 类逻辑块 + 全局互连，非易失，延迟可预测 |
| FPGA | 基于 LUT 的逻辑块 + 可编程互连，高密度、SRAM 型易失 |
| LUT | `k` 输入查找表 = `2^k` 个配置位 + `2^k` 选 1 的多路器 |
| 4-LUT | 16 个 SRAM 位 + 15 个 2:1 多路器，可实现任意 4 变量函数 |

## 1. PLD 的基本结构

### 1.1 与阵列 + 或阵列

任何组合逻辑都可以写成「与或式」（第 2 章）。PLD 用硬件阵列实现这个式子：

```
输入 ──► 输入缓冲（产生原变量与反变量）
                     │
                     ▼
              ┌─────────────┐
              │   与阵列     │  可编程：选择哪些输入相与，产生乘积项
              └─────────────┘
                     │
                     ▼
              ┌─────────────┐
              │   或阵列     │  可编程/固定：把乘积项相或
              └─────────────┘
                     │
                     ▼
                 输出宏单元（寄存器、极性、三态）
```

- **与阵列**决定「每一项由哪些输入相与」；
- **或阵列**决定「哪些乘积项相加」；
- **输出宏单元**提供寄存器、输出极性选择和反馈，使 PLD 也能实现时序逻辑。

### 1.2 编程元件

| 编程技术 | 可重编程 | 掉电保持 | 典型器件 |
|---|---|---|---|
| 熔丝（Fuse） | 否 | 是 | 早期 PROM、PAL |
| 反熔丝（Antifuse） | 否 | 是 | 高可靠 FPGA、军用器件 |
| EEPROM | 是 | 是 | GAL、CPLD |
| Flash | 是 | 是 | CPLD、Flash 型 FPGA |
| SRAM | 是 | 否（需重新配置） | 主流 FPGA |

「编程」就是按配置数据接通或断开阵列中的交叉点；SRAM 型器件断电后配置丢失，上电时必须从外部配置芯片或主机重新加载。

## 2. 早期 PLD：PROM、PLA、PAL、GAL

### 2.1 PROM

- 与阵列**固定**（就是地址译码器），或阵列**可编程**；
- 用 PROM 实现组合逻辑时，地址是输入变量，数据是输出函数值——本质是查表；
- 缺点：输入变量增加时容量指数增长，且只能实现「最小项之和」形式。

### 2.2 PLA（可编程逻辑阵列）

- 与阵列、或阵列**都可编程**；
- 灵活，但器件利用率低、速度慢、成本高，实际很少使用，主要作为教学模型。

### 2.3 PAL（可编程阵列逻辑）

- 与阵列**可编程**，或阵列**固定**；
- 每个输出对应固定数量的乘积项（如 8 个），适合实现中等复杂度的与或式；
- 输出类型：组合输出（如 PAL16L8）、寄存器输出（如 PAL16R8）；
- 编程方式：熔丝，**一次性**，写错只能换片；
- 优点：速度快、成本低；缺点：不可修改、灵活性有限。

### 2.4 GAL（通用阵列逻辑）

- 结构类似 PAL（可编程与阵列 + 固定或阵列），但用 **EEPROM** 工艺，可反复擦写；
- 关键改进是 **输出逻辑宏单元（OLMC）**：每个输出可配置为组合输出或寄存器输出、高有效或低有效、三态或反馈；
- 代表器件 GAL16V8（16 个输入、8 个输出）、GAL22V10；
- 与 PAL 引脚兼容，可直接替换，是 PAL 的升级品。

## 3. CPLD（复杂可编程逻辑器件）

### 3.1 结构

CPLD 把多个「PAL 类逻辑块」集成到一片芯片，并加入全局互连：

```
┌────────────────────────────────────────────┐
│  逻辑块 0        逻辑块 1        …          │
│  ┌─────────┐    ┌─────────┐                │
│  │ 与阵列   │    │ 与阵列   │                │
│  │ 或阵列   │    │ 或阵列   │                │
│  │ 宏单元   │    │ 宏单元   │                │
│  └─────────┘    └─────────┘                │
│        ▲              ▲                     │
│        └──── 全局互连矩阵 ────┘             │
│                     ▲                       │
│                  I/O 块                     │
└────────────────────────────────────────────┘
```

- **宏单元**：与或阵列 + 触发器 + 极性控制 + 三态输出，可配置为组合或时序逻辑；
- **全局互连**：把各逻辑块和 I/O 连接起来，延迟固定、可预测；
- **编程工艺**：EEPROM/Flash，**非易失**，上电即工作，无需外部配置芯片。

### 3.2 特点与应用

- 密度中等（几百到几千个宏单元），适合控制逻辑、接口转换、地址译码、「胶合逻辑」；
- 引脚到引脚的延迟固定（与布线无关），时序容易预测；
- 典型器件：Altera MAX7000/MAX II（EPM240）、Xilinx CoolRunner；
- 缺点：寄存器资源相对少，不适合大规模算法处理。

---

## 4. FPGA（现场可编程门阵列）

### 4.1 结构

```
┌─────────────────────────────────────────────┐
│  I/O │  CLB  │  CLB  │  BRAM  │  DSP  │ I/O │
│      │  CLB  │  CLB  │  CLB   │  CLB  │     │
│  ────┴── 可编程互连（布线开关 + 连线资源）────│
│  I/O │  CLB  │  CLB  │  BRAM  │  CLB  │ I/O │
└─────────────────────────────────────────────┘
```

- **CLB / 逻辑片**：由查找表（LUT）、触发器、进位链、多路器组成，是逻辑实现的基本单元；
- **可编程互连**：由连线段和开关盒构成，决定信号走线，是延迟的主要来源；
- **专用资源**：块 RAM（BRAM）、DSP 乘法器、时钟管理（PLL/MMCM）、高速收发器；
- **I/O 块**：支持多种电平标准。

### 4.2 编程方式

| 类型 | 配置存储 | 掉电 | 特点 |
|---|---|---|---|
| SRAM 型 | SRAM | 丢失 | 主流，可无限次配置，需外部配置芯片 |
| Flash 型 | Flash | 保持 | 上电即用，安全性好，密度较低 |
| 反熔丝型 | 反熔丝 | 保持 | 一次性，抗辐射、高可靠 |

SRAM 型 FPGA 每次上电都要加载**比特流（bitstream）**，因此电路板上通常还有一片配置 Flash。

### 4.3 设计流程

```
HDL 代码 → 功能仿真 → 综合（Synthesis）→ 布局布线（P&R）
        → 时序分析 → 生成比特流 → 下载到 FPGA
```

与 CPLD 相比，FPGA 的布线延迟与具体布局相关，必须做静态时序分析（STA）；CPLD 的延迟基本固定。

## 5. FPGA 的核心：查找表（LUT）

### 5.1 LUT 的结构

一个 `k` 输入的 LUT 由两部分组成：

1. **`2^k` 个配置位**（SRAM 单元），存放函数的真值表；
2. **`2^k` 选 1 的多路选择器**，由 `k` 个输入控制，选出对应的那一位。

```
         配置位 SRAM（2^k 位）
   ┌──┬──┬──┬── … ──┬──┐
   │b0│b1│b2│       │b15│
   └┬─┴┬─┴┬─┴       ┴┬─┘
    │  │  │           │
    └──┴──┴── 多路器 ──┴──► 输出 F
              ▲
        输入 i3 i2 i1 i0（选择端）
```

**关键认识**：LUT 不是「门电路」，而是一张**可编程真值表**——写入什么真值表，就实现什么函数。

### 5.2 4 输入 LUT（4-LUT）

- 配置位：`2^4 = 16` 位；
- 多路器：由 15 个 2:1 多路器组成树形结构：
  - 第 1 级 8 个，选择端 `i0`；
  - 第 2 级 4 个，选择端 `i1`；
  - 第 3 级 2 个，选择端 `i2`；
  - 第 4 级 1 个，选择端 `i3`。

因此一个 4-LUT 可以实现**任意** 4 变量组合函数（共有 `2^16 = 65536` 种）。

### 5.3 例：用 4-LUT 实现四变量奇校验

函数 `F = A ⊕ B ⊕ C ⊕ D`（输入中 1 的个数为奇数时输出 1）。真值表按 `ABCD = 0000～1111` 排列：

| ABCD | F | ABCD | F | ABCD | F | ABCD | F |
|---|---|---|---|---|---|---|---|
| 0000 | 0 | 0100 | 1 | 1000 | 1 | 1100 | 0 |
| 0001 | 1 | 0101 | 0 | 1001 | 0 | 1101 | 1 |
| 0010 | 1 | 0110 | 0 | 1010 | 0 | 1110 | 1 |
| 0011 | 0 | 0111 | 1 | 1011 | 1 | 1111 | 0 |

把 16 个函数值按「地址 15→0」写成二进制：`0110 1001 1001 0110 = 16'h6996`。这就是该 LUT 的配置内容。

- 当 `ABCD = 1011` 时，多路器选中第 11 号配置位，其值为 1，输出正确；
- 当 `ABCD = 0000` 时，选中第 0 号位，值为 0。

若把配置内容换成别的 16 位模式，同一个 LUT 就变成另一个函数——这正是 FPGA「通用硬件 + 可编程配置」的本质。

### 5.4 LUT 的扩展与限制

- **多输入函数**：用多个 LUT 级联实现；例如 5 输入函数可拆成两级 4-LUT；
- **资源配置**：`k` 越大，LUT 面积按 `2^k` 增长，因此主流 FPGA 采用 4～6 输入 LUT；
- **附加功能**：部分 FPGA 的 LUT 可配置为移位寄存器（SRL）或分布式 RAM；
- **时序**：LUT 本身延迟很小，但信号经过多级 LUT 与布线后累积，因此「逻辑级数」和「布线延迟」是 FPGA 时序的关键。

## 6. 四类器件对比

| 项目 | PAL | GAL | CPLD | FPGA |
|---|---|---|---|---|
| 基本结构 | 可编程与阵列 + 固定或阵列 | PAL + 输出宏单元（OLMC） | 多个 PAL 类逻辑块 + 全局互连 | CLB（LUT + 触发器）+ 可编程互连 |
| 编程元件 | 熔丝 | EEPROM | EEPROM / Flash | SRAM / Flash / 反熔丝 |
| 可重编程 | 否（一次性） | 是 | 是 | SRAM 型可反复配置；反熔丝型不可 |
| 掉电保持 | 是 | 是 | 是 | SRAM 型否（需重新加载）；Flash/反熔丝型是 |
| 集成度 | 低（数十门级） | 低（数百门级） | 中（几百～几千宏单元） | 高（百万门～亿门级） |
| 延迟特性 | 固定、快 | 固定、快 | 可预测（互连固定） | 与布局布线相关，需时序分析 |
| 逻辑实现 | 与或式（乘积项） | 与或式（乘积项） | 乘积项 + 宏单元 | 查找表（真值表）+ 触发器 |
| 典型应用 | 早期胶合逻辑 | 替换 PAL、小逻辑 | 控制、接口、地址译码、胶合逻辑 | 算法加速、图像/通信处理、原型验证、SoC |
| 代表器件 | PAL16L8 | GAL16V8 | MAX7000、EPM240 | Artix-7、Cyclone IV |

**选择建议**：

- 逻辑简单、需要上电即用、延迟确定 → CPLD；
- 逻辑复杂、需要大量寄存器/存储/DSP、可接受配置时间 → FPGA；
- 教学或维修旧设备 → GAL（可擦写，兼容 PAL）；
- 超高速、高可靠、一次性 → 反熔丝 FPGA 或专用 ASIC。

## 7. 自测题

1. PLD 的「与阵列 + 或阵列」分别决定与或式的哪一部分？
2. PAL 与 GAL 的关键区别是什么？
3. CPLD 为什么延迟可预测？FPGA 为什么需要时序分析？
4. 一个 4 输入 LUT 有多少个配置位？能实现多少种 4 变量函数？
5. 用 4-LUT 实现 `F = AB + C`，配置位应如何填写（给出 16 位内容）？
6. SRAM 型 FPGA 掉电后会发生什么？如何恢复？
7. 为什么说 LUT 本质是「真值表」而不是「门电路」？
8. CPLD 与 FPGA 分别适合什么类型的任务？

### 7.1 答案与解析

1. 与阵列决定每个乘积项由哪些输入相与（每一项的内容）；或阵列决定哪些乘积项相加（项与项的组合）。
2. PAL 用熔丝一次性编程、不可修改；GAL 用 EEPROM 可反复擦写，并增加输出宏单元（可配置组合/寄存器、极性、三态），且与 PAL 引脚兼容。
3. CPLD 的逻辑块之间通过固定的全局互连连接，路径延迟基本确定；FPGA 的互连由大量开关和分段连线组成，延迟取决于布局布线的具体结果，因此必须做静态时序分析。
4. `2^4 = 16` 个配置位；可实现 `2^16 = 65536` 种不同的 4 变量函数。
5. 按 `ABCD = 0000～1111` 求 `F = AB + C`：`F` 在 `C = 1` 或 `A = B = 1` 时为 1。逐项计算得 16 位（地址 15→0）为 `1111 1100 1100 1100`，即 `16'hFCCC`。（验证：`C=1` 的 8 个地址全为 1；`C=0` 时仅 `AB=11` 的 `1100、1101` 为 1，其余为 0，共 10 个 1。）
6. 配置信息丢失，逻辑功能消失；重新上电后由外部配置芯片或主机重新加载比特流（bitstream）。
7. LUT 内部是一组 SRAM 配置位加多路器，输出只是「按输入地址查出预先写入的那一位」，实现的是任意真值表；门电路只是其中一种特例，改变配置即可实现完全不同的函数。
8. CPLD 适合控制逻辑、接口转换、地址译码、上电即用的胶合逻辑；FPGA 适合大规模算法、图像/通信处理、高速接口、原型验证和 SoC 集成。
