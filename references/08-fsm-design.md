## 1. 有限状态机基础

### 1.1 定义

有限状态机由五要素描述：

1. **状态集合** `S = {S0, S1, …}`；
2. **输入集合** `X`；
3. **输出集合** `Y`；
4. **次态函数** `δ: S × X → S`；
5. **输出函数** `λ`（Mealy 为 `S × X → Y`，Moore 为 `S → Y`）。

状态机在时钟驱动下，按 `δ` 从一个状态迁移到另一个状态，并按 `λ` 产生输出。

### 1.2 状态图与状态表

**状态图**：圆圈表示状态，箭头表示转移，箭头旁标注「输入 / 输出」。

- Mealy：输出写在**转移边**上（输入与输出成对出现）；
- Moore：输出写在**状态圈内**（状态名/输出）。

**状态表**：行是现态，列是输入取值，表格内容是「次态 / 输出」。

### 1.3 同步状态机

本章讨论**同步**状态机：所有状态在同一个时钟沿更新，状态寄存器由 D 触发器构成，次态和输出都是组合逻辑。这正是第 4 章「同步时序电路」的特例。

## 2. Mealy 型与 Moore 型

### 2.1 定义与区别

| 项目 | Mealy 型 | Moore 型 |
|---|---|---|
| 输出函数 | `λ(现态, 输入)` | `λ(现态)` |
| 输出变化时刻 | 输入变化的同一拍（组合路径） | 状态变化的下一拍（或状态稳定后） |
| 状态图表示 | 输出标在转移边上 | 输出标在状态圈内 |
| 状态数 | 通常更少 | 通常多一个状态 |
| 响应速度 | 快（无需等状态更新） | 慢一拍 |
| 输出稳定性 | 依赖输入，输入有毛刺则输出可能毛刺 | 只由状态决定，较稳定 |
| 组合路径 | 输入直接连到输出逻辑 | 输出只与状态有关 |

### 2.2 时序对比

设输入序列在 `t1` 时刻完成「1011」：

- **Mealy**：在 `t1` 这一拍（第 4 个 1 到来时）输出立即为 1；
- **Moore**：在第 4 个 1 被时钟采样、状态进入 `S4` 之后，下一拍输出才为 1。

因此同一功能，Moore 的输出比 Mealy **晚一个时钟周期**。

### 2.3 选择建议

- 输出需要与输入同拍响应、状态数要少 → Mealy；
- 输出要求稳定、避免输入毛刺影响、便于时序约束 → Moore；
- 实际工程中常把 Mealy 输出再打一拍（寄存器输出），兼顾速度与稳定性。

## 3. 状态编码

| 编码方式 | 状态位宽（`n` 个状态） | 优点 | 缺点 | 适用 |
|---|---|---|---|---|
| 二进制 | `⌈log₂n⌉` | 触发器少 | 译码逻辑复杂 | CPLD、资源紧张 |
| 独热码（One-hot） | `n` | 译码简单、速度快 | 触发器多 | FPGA（触发器资源丰富） |
| 格雷码 | `⌈log₂n⌉` | 相邻状态只变 1 位，降低翻转功耗 | 编码受限 | 低功耗、异步接口 |

编码方式只影响实现，不改变状态机的功能。写代码时用 `localparam` 定义状态名，综合工具也可以自动重新编码（可配置）。

## 4. 状态化简

### 4.1 等价状态

两个状态 `Si`、`Sj` 等价，当且仅当：

1. 对**所有输入**，两者的输出相同（Moore 比较状态输出；Mealy 比较每条转移上的输出）；
2. 对**所有输入**，两者的次态等价（或为同一状态）。

等价状态可以合并，合并后状态机行为不变。

### 4.2 分区法（划分法）

1. 按输出把状态分组（输出相同的放一组）；
2. 检查每组内各状态：对每个输入，若次态落在不同组，则把它们拆开；
3. 重复第 2 步，直到分组不再变化；
4. 每个最终分组合并成一个状态。

### 4.3 化简示例

某 Moore 状态机（4 个状态，1 个输入 `x`，输出 `z`）：

| 现态 | `x=0` 次态 | `x=1` 次态 | 输出 `z` |
|---|---|---|---|
| A | A | B | 0 |
| B | A | C | 0 |
| C | D | C | 1 |
| D | D | C | 1 |

**第 1 步**：按输出分组：`P0 = {A, B}, {C, D}`。

**第 2 步**：

- 检查 `{A, B}`：
  - `x = 0` 时，A→A、B→A，都在 `{A,B}` 组内，暂不拆分；
  - `x = 1` 时，A→B（在 `{A,B}`），B→C（在 `{C,D}`），**不同组** → A、B 拆开。
- 检查 `{C, D}`：
  - `x = 0` 时，C→D、D→D，都在 `{C,D}`；
  - `x = 1` 时，C→C、D→C，都在 `{C,D}` → 保持同组。

得到 `P1 = {A}, {B}, {C, D}`。

**第 3 步**：再检查 `{C, D}`，次态仍全部落在同组，分组稳定。

**结论**：C 与 D 等价，可合并为 `C'`，状态数从 4 降为 3：

| 现态 | `x=0` | `x=1` | 输出 |
|---|---|---|---|
| A | A | B | 0 |
| B | A | C' | 0 |
| C' | C' | C' | 1 |

验证：原状态机中 C、D 的输出都是 1，且无论输入如何都在 C、D 之间或自身循环，行为完全一致，合并安全。

### 4.4 注意事项

- Mealy 机的输出在转移边上，比较等价时要把「输入 → 输出」整体比较，不能只看状态；
- 含无关项（不完全指定）的状态机，可把无关转移当作有利条件化简；
- 化简后要重新检查未用状态与自启动。

## 5. Verilog 三段式写法

### 5.1 三段式的结构

```verilog
// 段 1：状态寄存器（时序）
always @(posedge clk or negedge rst_n)
    if (!rst_n) state <= S_IDLE;
    else        state <= next_state;

// 段 2：次态组合逻辑
always @(*) begin
    next_state = state;              // 默认值，防止锁存器
    case (state)
        S_IDLE: if (start) next_state = S_RUN;
        S_RUN:  if (done)  next_state = S_DONE;
        S_DONE:            next_state = S_IDLE;
        default:           next_state = S_IDLE;   // 安全状态
    endcase
end

// 段 3：输出组合逻辑
always @(*) begin
    out = 1'b0;                      // 默认值
    case (state)
        S_RUN:  out = 1'b1;
        default: out = 1'b0;
    endcase
end
```

### 5.2 为什么用三段式

1. **职责分离**：时序只写时钟沿，组合只写逻辑，便于阅读和调试；
2. **避免锁存器**：段 2、段 3 都有默认赋值，所有分支覆盖；
3. **便于修改**：改输出不影响状态转移；
4. **综合结果稳定**：综合工具能明确识别状态寄存器与组合逻辑。

### 5.3 两段式与一段式

- **两段式**：状态寄存器 + 「次态与输出」合并的 `always`，代码短，但输出逻辑与状态转移耦合；
- **一段式**：所有逻辑写在时钟沿的 `always` 中，输出是寄存器输出（延迟一拍），可读性差，通常不推荐。

### 5.4 编码与复位

```verilog
localparam S0 = 2'b00,
           S1 = 2'b01,
           S2 = 2'b10,
           S3 = 2'b11;
```

- 用 `localparam` 而不是 `parameter`，防止被外部误改；
- 状态寄存器用异步或同步复位，与全系统复位策略一致；
- 未用状态在 `default` 分支回到安全状态，保证「自启动」。

## 6. 完整设计：1011 序列检测器

### 6.1 需求

- 在串行输入 `din` 中检测「1011」；
- **重叠检测**：`1011011` 中应检测到两次（第 4 位和第 7 位完成）；
- 采用 **Mealy 型**、同步设计、低电平异步复位；
- 检测成功时 `dout` 输出一个时钟周期的高电平。

### 6.2 状态定义（Mealy，4 状态）

| 状态 | 含义 |
|---|---|
| `S0` | 尚未匹配任何前缀 |
| `S1` | 已收到「1」 |
| `S2` | 已收到「10」 |
| `S3` | 已收到「101」 |

### 6.3 状态图（表格式）

| 现态 | `din = 0` | `din = 1` | 说明 |
|---|---|---|---|
| `S0` | `S0 / 0` | `S1 / 0` | 收到 1 进入 S1 |
| `S1` | `S2 / 0` | `S1 / 0` | 收到 10 进入 S2；连续 1 保持 S1 |
| `S2` | `S0 / 0` | `S3 / 0` | 收到 101 进入 S3；100 回到 S0 |
| `S3` | `S2 / 0` | `S1 / 1` | 1011 检测成功，输出 1；1010 回到 S2 |

说明 S3 的两个转移：

- `din = 0`：输入变为「1010」，最长可复用后缀是「10」，回到 `S2`；
- `din = 1`：输入变为「1011」，检测成功，输出 1；同时最长可复用后缀是「1」，回到 `S1`（支持重叠）。

### 6.4 状态编码

```verilog
localparam S0 = 2'b00,
           S1 = 2'b01,
           S2 = 2'b10,
           S3 = 2'b11;
```

4 个状态用 2 位二进制编码，全部状态都被使用，不存在未用状态（`default` 仍保留作为安全兜底）。

### 6.5 输出方程

Mealy 输出只在「现态为 S3 且输入为 1」时为 1：

```
dout = (state == S3) && din
```

若采用 Moore 型，则需要增加 `S4` 状态，输出 `dout = (state == S4)`，检测结果晚一拍。

### 6.6 Verilog 代码（三段式）

```verilog
module seq_det_1011 (
    input  wire clk,
    input  wire rst_n,      // 低电平异步复位
    input  wire din,
    output reg  dout
);

    localparam S0 = 2'b00,
               S1 = 2'b01,
               S2 = 2'b10,
               S3 = 2'b11;

    reg [1:0] state, next_state;

    // 段 1：状态寄存器
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            state <= S0;
        else
            state <= next_state;
    end

    // 段 2：次态逻辑
    always @(*) begin
        case (state)
            S0: next_state = din ? S1 : S0;
            S1: next_state = din ? S1 : S2;
            S2: next_state = din ? S3 : S0;
            S3: next_state = din ? S1 : S2;
            default: next_state = S0;
        endcase
    end

    // 段 3：输出逻辑（Mealy：依赖 state 与 din）
    always @(*) begin
        dout = (state == S3) && din;
    end

endmodule
```

### 6.7 Testbench（自检）

```verilog
`timescale 1ns/1ps

module tb_seq_det_1011;

    reg  clk;
    reg  rst_n;
    reg  din;
    wire dout;

    integer errors;

    seq_det_1011 dut (
        .clk   (clk),
        .rst_n (rst_n),
        .din   (din),
        .dout  (dout)
    );

    initial clk = 1'b0;
    always #5 clk = ~clk;           // 10 ns 周期

    // 在下降沿改变输入，上升沿前保持稳定
    task apply_bit;
        input b;
        input exp;
        begin
            @(negedge clk);
            din = b;
            #1;                      // 等待组合逻辑稳定
            if (dout !== exp) begin
                errors = errors + 1;
                $display("ERROR @%0t: din=%b dout=%b exp=%b", $time, din, dout, exp);
            end
        end
    endtask

    initial begin
        errors = 0;
        rst_n  = 1'b0;
        din    = 1'b0;

        repeat (2) @(posedge clk);
        @(negedge clk) rst_n = 1'b1;

        apply_bit(1'b1, 1'b0);
        apply_bit(1'b0, 1'b0);
        apply_bit(1'b1, 1'b0);
        apply_bit(1'b1, 1'b1);      // 1011 检测成功
        apply_bit(1'b0, 1'b0);
        apply_bit(1'b1, 1'b0);
        apply_bit(1'b1, 1'b1);      // 重叠检测：再次成功
        apply_bit(1'b0, 1'b0);
        apply_bit(1'b0, 1'b0);

        #10;
        if (errors == 0)
            $display("PASS: 1011 detector, overlapping");
        else
            $display("FAIL: %0d errors", errors);
        $finish;
    end

endmodule
```

### 6.8 仿真过程追踪

输入序列 `1011 011`（共 7 位），每个下降沿施加一位：

| 时钟拍 | `din` | 现态（施加上一位之后） | `dout` | 说明 |
|---|---|---|---|---|
| 1 | 1 | S0 | 0 | 进入 S1 |
| 2 | 0 | S1 | 0 | 进入 S2 |
| 3 | 1 | S2 | 0 | 进入 S3 |
| 4 | 1 | S3 | **1** | 检测到 1011 |
| 5 | 0 | S1 | 0 | 10110，最长后缀「10」→ S2 |
| 6 | 1 | S2 | 0 | 进入 S3 |
| 7 | 1 | S3 | **1** | 重叠检测到 1011 |
| 8 | 0 | S1 | 0 | 10110，回到 S2 |

注意 `dout` 在 `din` 变化的同一拍就有效（Mealy 特性），持续到下一个时钟沿状态更新之前。

### 6.9 Moore 型变体

若要求输出稳定、避免输入毛刺影响，可改用 Moore 型，增加 `S4`：

| 现态 | `din = 0` | `din = 1` | 输出 |
|---|---|---|---|
| `S0` | `S0` | `S1` | 0 |
| `S1` | `S2` | `S1` | 0 |
| `S2` | `S0` | `S3` | 0 |
| `S3` | `S2` | `S4` | 0 |
| `S4` | `S2` | `S1` | 1 |

- 输出改为 `dout = (state == S4)`，比 Mealy 晚一拍；
- `S4` 的两个转移与 Mealy 的 `S3` 相同（`S4` 在 `din=1` 时也回到 `S1`，保持重叠能力）；
- 状态数 5，需要 3 位编码（或独热码 5 位）。

### 6.10 非重叠变体

若要求「检测到一次后重新开始」，只需把 `S3` 的 `din=1` 转移改为 `S0`：

```verilog
S3: next_state = din ? S0 : S2;   // 非重叠：检测后回到 S0
```

此时输入 `1011011` 只会检测到第一次，第二次因重新从 `S0` 开始而错过。

### 6.11 状态化简说明

- 本设计的 4 个 Mealy 状态两两不等价：它们对同一输入的后继状态不同，且只有 `S3` 在 `din=1` 时输出 1；
- Moore 变体的 5 个状态同样不可再合并：`S0～S3` 输出为 0、`S4` 输出为 1，输出已把 `S4` 区分开；其余 4 个状态的后继关系也各不相同；
- 若状态数很多，先按第 4 节分区法化简，再编码，可显著减少触发器与译码逻辑。

## 7. 常见错误与设计建议

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 段 2、段 3 没有默认赋值 | 综合出锁存器 | 进入 `case` 前先赋默认值 |
| `case` 缺 `default` | 未用状态行为不确定 | 加 `default` 回到安全状态 |
| 时序块用阻塞赋值 | 仿真/综合不一致 | 段 1 用 `<=` |
| 输出直接由输入组合产生且未寄存 | 毛刺传播 | 需要时给输出加一级寄存器 |
| Mealy 与 Moore 混用输出条件 | 输出时序错乱 | 明确机型，按定义写输出 |
| 状态编码随意、未用状态未处理 | 上电可能进入非法状态 | 用 `localparam` 编码，`default` 兜底 |

**设计建议**：

1. 先画状态图/表，再写代码；
2. 状态数尽量少（先化简）；
3. 输出若直接驱动外部引脚，考虑寄存器输出；
4. 对安全关键设计，检查所有未用状态的自启动路径；
5. 用 Testbench 覆盖：正常序列、重叠序列、非重叠序列、复位、连续无效输入。

## 8. 自测题

1. Mealy 型与 Moore 型的输出分别由什么决定？
2. 同一个序列检测功能，为什么 Mealy 的状态数通常比 Moore 少？
3. 状态等价的判定条件是什么？
4. 三段式写法中，哪一段使用非阻塞赋值？为什么？
5. 组合 `always` 中漏写 `default` 可能综合出什么？
6. 1011 检测器（Mealy、重叠）在输入 `1011011` 中会输出几次？分别在第几位之后？
7. 若把 1011 检测器改成非重叠，`S3` 在 `din=1` 时应转移到哪个状态？
8. 独热码适合 FPGA 还是 CPLD？为什么？

### 8.1 答案与解析

1. Mealy：输出由现态和当前输入共同决定；Moore：输出只由现态决定。
2. Mealy 可以在「检测成功的那个转移」上直接输出，不需要额外的「成功状态」；Moore 必须进入一个专门的输出状态，通常多一个状态。
3. 两个状态对所有输入的输出相同，且对所有输入的后继状态等价（或相同）。
4. 段 1（状态寄存器）使用 `<=`，因为状态需要在时钟沿同时更新，非阻塞赋值符合时序逻辑的「同一时刻更新」语义，避免竞争。
5. 可能综合出锁存器（未赋值时保持原值），并导致未用状态行为不确定。
6. 两次：第 4 位之后（1011）和第 7 位之后（重叠的 1011）。
7. 应转移到 `S0`（检测完成后重新开始，不再复用已匹配的后缀）。
8. 适合 FPGA。FPGA 触发器资源丰富，独热码每位一个触发器，译码只需看对应位，速度快；CPLD 触发器较少，通常用二进制编码节省资源。
